# HTTP, события и webhook

Все HTTP-маршруты требуют `X-API-Key`, включая системную схему и Swagger.

| Операция | Маршрут | Результат |
| --- | --- | --- |
| Создание платежа | `POST /api/v1/payments` | 202, UUID, текущий статус, дата создания |
| Чтение платежа | `GET /api/v1/payments/{payment_id}` | 200, подробное состояние |

В POST обязателен `Idempotency-Key`: 1–255 символов без пробелов.
Тело: `amount`, `currency`, `description`, `metadata`, `webhook_url`.
Поддерживаются RUB/USD/EUR, положительная сумма с точностью до копейки,
описание 1–1000 символов, HTTP(S)-URL. Неизвестные поля и NaN/Infinity отклоняются.
Повтор одинакового запроса возвращает тот же платёж; другое тело — 409.
Ошибки ключа — 401, отсутствующего платежа — 404, формы запроса — 422.

Примеры запросов находятся в [быстром запуске](../../../guides/quickstart.md).
Точные ограничения и поля ответа доступны в [DTO автодокументации](autodoc.md).

## Событие payments.new

```json
{
  "event_id": "01926c00-7b9e-4fc4-a1ef-000000000001",
  "payment_id": "389ce875-f76d-49e1-b2c0-f1895084d4d5",
  "attempt": 1,
  "version": 1
}
```

`PaymentEventMessage` валидирует сообщение и создаёт доменный `PaymentEvent`.
При retry создаётся новый `event_id`, `attempt` увеличивается; `payment_id`
сохраняется. Consumer проверяет совпадение сообщения с записью Outbox.

## Webhook

```json
{
  "event_id": "01926c00-7b9e-4fc4-a1ef-000000000002",
  "payment_id": "389ce875-f76d-49e1-b2c0-f1895084d4d5",
  "status": "succeeded",
  "amount": "1500.00",
  "currency": "RUB",
  "metadata": {"order_id": "42"},
  "processed_at": "2026-10-03T10:00:04+00:00"
}
```

Сумма — строка, дата — ISO 8601 в UTC. Заголовки `Idempotency-Key` и
`X-Webhook-Event-ID` равны `event_id` уведомления. Повторные попытки сохраняют
его; получатель должен дедуплицировать уведомления по этому значению.

Успех доставки — любой 2xx. Таймаут, ошибка сети, редирект или другой HTTP-код
вызывают retry. После исчерпания попыток успешный статус платежа сохраняется,
а событие с диагностикой публикуется в `payments.dead`.
