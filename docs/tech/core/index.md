# Ядро

Ядро содержит общие механизмы приложения и не импортирует доменные модули.

| Подсистема | Контракт |
| --- | --- |
| `db.contracts` | Атомарный контекст с явным commit/rollback |
| `db.unit_of_work` | Управление SQLAlchemy-сессией |
| `events.models` | Событие любого агрегата с состоянием публикации |
| `events.contracts` | Порты Outbox и publisher confirms |
| `events.outbox` | Выбор пачки, повтор публикации, фоновый опрос |
| `events.rabbitmq` | Persistent-публикация по внедрённой таблице маршрутов |
| `auth.dependencies` | Проверка X-API-Key |
| `errors.handlers` | Регистрация публичных HTTP-представлений ошибок |
| `utils` | UTC и экспоненциальная задержка |

Настройки процессов валидируются в `ApiSettings`, `WorkerSettings` и `DatabaseSettings`. Диспетчер получает узкие
`OutboxOptions`, а не всю конфигурацию API: для публикации ему достаточно
размера пачки и интервала опроса.

Платёжный модуль реализует хранилище Outbox и определяет топологию сообщений.
Ядро публикует события по переданной таблице маршрутов; оно не знает названий
`payments.new` и `payments.dead`.
