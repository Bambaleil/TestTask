# Асинхронный сервис платежей

Сервис принимает платёж через HTTP, сохраняет его и событие атомарно,
обрабатывает оплату через эмулятор провайдера и доставляет результат webhook.

Архитектура использует разделение ядра и доменных модулей:
`views → repository → DAO`. Дополнительно доменные сущности и порты отделены
от фреймворков, а `UnitOfWork` управляет атомарностью платежа и Outbox.

## Документация из исходников

Страницы «Автодокументация» собираются из текущих аннотаций и докстрингов
через MkDocs Material и mkdocstrings. Ручная копия описаний методов не требуется.
HTTP-схема `/openapi.json` формируется FastAPI; статический JSON в репозитории
не хранится. Документация объясняет контракт, а Swagger позволяет выполнить запрос.

```bash
make docs       # Собрать HTML в .build/docs/ со строгой проверкой
make docs-serve # Просмотреть документацию локально
```
