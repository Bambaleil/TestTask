# История изменений
## 0.4.1

- Покрытие тестов 100%
## 0.4.0

- Локальный Compose и Grafana/Loki/Alloy вынесены в deploy/local; добавлен production-пример с внешними зависимостями, отдельной миграцией и файловой системой контейнеров только для чтения.
- Разделены настройки API, consumer и миграций; журнал пишется только в stdout, лимиты пула БД настраиваются через окружение.
- Обновлены инструкции выпуска и наблюдаемости; сборка HTML перемещена в .build/docs, локальные команды сведены в Makefile.


## 0.3.0

- Добавлены JSON-логи API/consumer, сборщик Alloy, Loki и Grafana с готовым дашбордом.
- Добавлены liveness/readiness API и consumer с проверкой БД, брокера и задачи Outbox.
- Добавлены pre-commit/pre-push.
- Описаны логи, диагностика, проверки Git и выпуск changelog.


## 0.2.0

- Ядро отделено от модуля платежей; введены слои views, repository и DAO.
- Доменные сущности и контракты не зависят от ORM, HTTP и брокера.
- Добавлены явный Unit of Work, преобразование ORM-записей и единая сборка зависимостей.
- HTTP-контракты, таблицы и гарантии Outbox/retry/DLQ сохранены.
- Точки входа перенесены в `payment_service.server` и `payment_service.worker`.
- Добавлены русские Google-докстринги и MkDocs-автодокументация.

## 0.1.0

- Реализованы API платежей, статический API-ключ, идемпотентность, Outbox,
  эмуляция шлюза, webhook, повторные попытки и DLQ.
- Добавлены Alembic, Docker Compose, Ruff, mypy и тесты PostgreSQL/RabbitMQ.
